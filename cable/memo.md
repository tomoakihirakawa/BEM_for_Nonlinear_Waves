## 橋梁ケーブルの風応答解析への拡張メモ

### 背景と方針

本コードは海中係留索（チェーン）を念頭に組まれているが，**橋梁ケーブルの風振動解析**
への流用要望があった．以下，拡張方針をまとめる．

**スコープ**:

- 端点：両端固定（デフォルト**ピン支持**，疲労評価時はクランプ／半剛性に切替）
- 荷重：自重＋プリテンション＋風荷重
- **疲労評価あり**（端部応力を見るので EI と回転拘束が必要）
- **動的境界あり**（主桁運動入力によるパラメトリック励振等を対象に含む）

### 海中係留索 vs 橋梁ケーブル

| 項目 | 海中係留索 | 橋梁ケーブル |
|---|---|---|
| 主荷重 | 自重＋浮体運動＋海流 | 自重＋風＋プリテンション |
| 形状 | カテナリ（大垂下） | ほぼ直線＋微少サグ |
| 端点 | アンカー＋フェアリード | 両端固定 |
| 振幅 / cable長 | 大（10⁻¹） | 小（10⁻³〜10⁻²） |
| 主モード | 非線形大変形 | 線形横振動＋局所非線形 |
| 周波数帯 | 0.01〜0.5 Hz | 0.5〜10 Hz（弦モード） |
| 構造減衰 | 中 | **極小（0.1〜0.5%臨界）** |
| 主現象 | カテナリ引張，touchdown 衝撃 | VIV，ギャロッピング，レインバイブレーション，バフェッティング |

### ベースモデル：既存コードの 9 割が使える

横振動は**軸方向ばね＋集中質量モデルから自動的に湧いて出る**．節点を結ぶ
線分長を $L_0$，プリテンション $T_0$ で一様に引張られた状態を初期に取り，
節点 $i$ が接線 $\hat s$ に直交する $\hat n$ 方向に微小変位 $u_i$ するとする．
隣接線分の単位ベクトルは

$$\hat e_{i\to i\pm 1} = \pm\hat s + \frac{u_{i\pm 1} - u_i}{L_0}\hat n + \mathcal{O}(u^2/L_0^2)$$

両側の張力 $T_0$ を節点 $i$ に集約すると，$\hat n$ 方向の戻し力は

$$F_n^{(i)} = T_0\,\frac{u_{i+1} - 2u_i + u_{i-1}}{L_0}$$

これは離散ラプラシアン $L_0\cdot \partial^2 u/\partial s^2$ に $T_0$ を掛けたものに等しく，
$L_0\to 0$ の連続極限で **taut string の方程式**

$$\mu\,\frac{\partial^2 u}{\partial t^2}
= T_0\,\frac{\partial^2 u}{\partial s^2} + f(s,t),
\qquad \mu \equiv \rho A$$

に収束する（$\mu$ は線密度 [kg/m]）．つまり既存の `getTension()`

```cpp
force += l->stiffness * strain * Normalize(v);
```

はベクトルの**向き**を毎ステップ更新する設計なので，幾何学的非線形ばねが
**そのまま taut string の離散化**になっている．**横振動方程式を別途書く必要なし．**

#### プリテンションの仕込み方

自重を無視した直線状態において，自然長 $L_0^\text{tot}$ の cable を
chord 長 $L_c$ に張ったときの軸ひずみは
$\varepsilon = (L_c - L_0^\text{tot})/L_0^\text{tot}$，対応する張力は
$T = EA\,\varepsilon$．目標プリテンション $T_0$ を満たす自然長は

$$L_0^\text{tot} = \frac{L_c}{1 + T_0/EA}$$

これを節点数 $N+1$ に対して $L_0 = L_0^\text{tot}/N$ と等分し，各 `networkLine` の
`natural_length` に与える．

自重サグを含めた厳密な初期形状は閉形式で書けないので，**この自然長を初期値として
`setEquilibriumState()` を回し，動的緩和でカテナリ平衡に落とす**のが実装上の手順．
平衡後は，無次元 Irvine パラメータ

$$\lambda^2 = \left(\frac{\mu g L_c\cos\theta}{T_0}\right)^2\frac{EA\,L_c}{T_0\,L_e},
\qquad L_e = L_c\left[1 + \frac{1}{8}\!\left(\frac{\mu g L_c\cos\theta}{T_0}\right)^{\!2}\right]$$

（$\theta$ は弦の鉛直からの傾角）が小さければ，最終 chord 長は元の $L_c$ から
ほとんどずれない．$\lambda^2 \gtrsim 1$ では対称面内モードに非線形補正が出るが，
これも幾何ばねモデルが内包する．

### 知識メモ：幾何学非線形（geometric nonlinearity）とは

本コードの質点ばねモデルが「弦の方程式を別途書かなくても taut string を再現できる」
理由の核心は**幾何学非線形**にある．以下，定義と意味を整理する．

#### 定義

> **物体の変形に伴って，力と変位の関係が「変形後の形状」によって決まることから
> 生じる非線形性．**

材料は線形（フックの法則）のままでも，**形が変わること自体**から非線形が出る．
これに対して**材料非線形**は応力-ひずみ関係そのものが非線形（塑性，超弾性等）の
場合を指す．両者は独立で，「線形材料＋幾何非線形」が普通の組合せ．

#### このコードでの現れ方

[Network.hpp:597-602](../lib/include/Network.hpp#L597-L602)：

```cpp
v = (*l)(this)->RK_X_sub.getX() - this->RK_X_sub.getX();
disp = Norm(v) - l->natural_length;
strain = disp / l->natural_length;
if (disp > 0.)
   force += l->stiffness * strain * Normalize(v);
```

- **材料側**：`stiffness * strain` $= EA\varepsilon$（フックの法則，線形）
- **幾何側**：`Normalize(v)` で**現在のセグメント方向**に力を向ける
- **幾何側**：`Norm(v)` で**現在のセグメント長**から伸びを測る

つまり力の大きさ自体は $\varepsilon$ に線形でも，**力の向きと作用点が変形後の幾何で
決まる**．これが幾何非線形の本体．

#### 弦の戻し力が湧く仕組み

プリテンション $T_0$ で張られた状態から節点 $i$ が $\hat n$ 方向に微小変位 $u_i$ する．
隣接線分の単位ベクトルは

$$\hat e_{i\to i\pm 1} = \pm\hat s + \frac{u_{i\pm 1}-u_i}{L_0}\hat n
+ \mathcal{O}(u^2/L_0^2)$$

**$T_0$ の大きさは変わらない**が，**ベクトルの向きが微小回転する**ので，両端からの
張力の $\hat n$ 方向成分が

$$F_n^{(i)} = T_0\,\frac{u_{i+1}-2u_i+u_{i-1}}{L_0}$$

として現れる．**「大きさ」ではなく「向きの傾き」から戻し力が湧く**のがポイント．

もし軸力を常に初期接線方向 $\hat s$ に固定する（完全線形化する）と，横方向成分は
恒等的にゼロで弦は剛体になる．**弦理論 $\mu\ddot u = T_0 u''$ ですら，
実は幾何非線形を $u$ の1次まで展開したもの**である．

#### この区別が効く場面

| 現象 | 必要な非線形 |
|---|---|
| バネの伸縮 $F=k\Delta x$ | 不要（純線形でOK） |
| **弦・ケーブルの横振動** | **幾何非線形必須** |
| **大変形カテナリ（係留）** | **幾何非線形必須** |
| 棒の座屈 | 幾何非線形（座屈後経路） |
| 梁の大たわみ | 幾何非線形 |
| Mathieu 不安定（パラメトリック共振） | 幾何非線形 |
| 鋼の塑性 | 材料非線形 |
| ゴムの大ひずみ | 材料非線形＋幾何非線形 |

橋梁ケーブルではひずみ自体は微小（$10^{-4}$ オーダー）で材料は完全に線形だが，
**変形後の形状で力を向けないと弦の振動が出ない**ので幾何非線形が必須．

#### 質点ばねモデルの恩恵

$$\vec F = EA\cdot\varepsilon(\vec X(t))\cdot\hat e(\vec X(t))$$

と書くだけで幾何非線形が**自動的に入る**ので，

1. 線形領域（小振幅，taut string）
2. 弱非線形領域（大振幅，Duffing 型硬化ばね）
3. 強非線形領域（大変形カテナリ，touchdown）

を**同じ方程式でシームレスに**解ける．モード展開アプローチでは線形領域から
出るたびに非線形補正項を別途付け足す必要があり，コードが分裂する．

#### 一行まとめ

> **幾何学非線形 ＝ 材料は線形でも，変形後の幾何（位置・向き・長さ）で力を計算する
> ことから生じる非線形性．弦の戻し力，カテナリ，座屈，パラメトリック共振などを
> 生む．質点ばねモデルは「向き」を毎ステップ更新するだけで自動的にこれを内包する．**

#### (b) 風速場 U_wind(s, t) の注入

最小実装は一様風 `{U0, 0, 0}`．発展形：

- 高度プロファイル： `U(z) = U_ref · (z/z_ref)^α`
- 乱流入力：Davenport / von Karman スペクトルから時系列生成
- ガストモデル：`U(t) = U_mean + u'(t)`

#### (c) 準定常空力（quasi-steady aerodynamics）

橋梁ケーブル振動の業界標準モデル．円柱の**独立性原理**（independence principle）
に従い，ケーブル軸方向流れ成分は無視して**法線方向成分だけが空力を生む**とする．

ケーブル接線単位ベクトルを $\hat t$，相対風速を

$$\vec U_\text{rel} = \vec U_\text{wind}(s,t) - \vec v_\text{cable}$$

と定義し，その法線成分を

$$\vec U_n = \vec U_\text{rel} - (\vec U_\text{rel}\cdot\hat t)\,\hat t$$

と分解する．ケーブル単位長さあたりの空力は

$$\vec f_\text{aero}
= \tfrac{1}{2}\rho_\text{air} D \,|\vec U_n|
\Bigl(C_D(\alpha)\,\vec U_n + C_L(\alpha)\,|\vec U_n|\,\hat n_L\Bigr)$$

ここで $D$ は直径，$\hat n_L = \hat t \times \hat U_n$ は揚力方向単位ベクトル，
$\alpha$ は断面に対する $\hat U_n$ の迎角．**節点速度を $\vec U_\text{rel}$ に
含める**ことで以下が自動的に得られる：

- **空力減衰**（aerodynamic damping）：振動方向の $\dot u$ が
  $\vec v_\text{cable}$ を介して $\vec U_\text{rel}$ に入り，線形項として
  正の減衰係数を生成する．
- **ギャロッピング不安定**：振動方向の準定常空力減衰係数（単位長さあたり）は
  $$c_\text{aero} = \tfrac{1}{2}\rho_\text{air} U D
  \left(\left.\frac{\partial C_L}{\partial\alpha}\right|_{\alpha_0} + C_D(\alpha_0)\right)$$
  これが負になる断面形状（D 型，矩形等）では発散．これが **Den Hartog 条件**：
  $$\left.\frac{\partial C_L}{\partial\alpha}\right|_{\alpha_0} + C_D(\alpha_0) < 0$$

円形断面では $C_L\equiv 0$，$\partial C_L/\partial\alpha=0$ なので Den Hartog 不安定
は生じず，振動はもっぱら **VIV** とレインバイブレーションが支配する．

`getDragForce()` ([Network.hpp:609-636](../lib/include/Network.hpp#L609-L636))
には既に相対速度を引く部分があるので，係数差し替えと風速注入で動く．

#### (d) 構造減衰を別途加える

橋梁ケーブルの構造減衰比 $\zeta_s$ は 0.001〜0.005（0.1〜0.5%臨界）と極小で，
**VIV やギャロッピングの振幅を決める支配パラメータ**．現状の `damping` メンバは
隣接節点間の相対速度減衰（材料粘性）なので，**節点絶対速度に対する
Rayleigh 減衰**を追加する：

$$\mathbf{C} = \alpha\mathbf{M} + \beta\mathbf{K}$$

ここで $\mathbf{M}, \mathbf{K}$ は系の質量・剛性行列．最小実装としては
$\beta\mathbf{K}$ 項は省略し質量比例項だけで十分：

```cpp
F_damp = -alpha * mass * velocity;   // 質量比例（低周波支配）
```

第 $n$ モードの減衰比は

$$\zeta_n = \frac{1}{2}\!\left(\frac{\alpha}{\omega_n} + \beta\,\omega_n\right)$$

2つの目標 $(\omega_1,\zeta_1),(\omega_2,\zeta_2)$ から $\alpha,\beta$ を逆算：

$$\alpha = \frac{2\,\omega_1\omega_2(\zeta_1\omega_2 - \zeta_2\omega_1)}{\omega_2^2 - \omega_1^2},
\qquad
\beta = \frac{2(\zeta_2\omega_2 - \zeta_1\omega_1)}{\omega_2^2 - \omega_1^2}$$

質量比例項単独 ($\beta=0$) なら $\alpha = 2\zeta_1\omega_1$．低次モードを目標に
合わせると高次モードは $\zeta_n = \zeta_1(\omega_1/\omega_n)$ で過小減衰になる点に注意．

#### (e) 境界条件の選択（疲労評価のため重要）

**ピン／クランプ／半剛性の3択**．本案件では**疲労評価をスコープに含む**ので，
中央部解析と端部解析でモードを切り替える設計が必要．

| BC種別 | 拘束 | 物理的意味 | 必要条件 |
|---|---|---|---|
| **ピン**（デフォルト） | 位置固定，M=0 | 端点で自由回転．弦の標準BC | EI=0でOK |
| **クランプ** | 位置＋接線方向固定 | モーメント伝達あり | **EI > 0 必須** |
| **半剛性** | 位置固定＋$M=k_\theta\Delta\theta$ | 実橋アンカーに最も近い | EI > 0 ＋ $k_\theta$ |

**重要な性質**：

- **固有振動数（ピン-ピン，$T_0$＋$EI$）**：モード形状は $\sin(n\pi s/L)$ のままで
  $$\omega_n^2 = \frac{n^2\pi^2}{\mu L^2}\!\left(T_0 + \frac{n^2\pi^2 EI}{L^2}\right),
  \quad
  f_n = \frac{n}{2L}\sqrt{\frac{T_0}{\mu}}\sqrt{1 + \frac{n^2\pi^2 EI}{T_0 L^2}}$$
  曲げ補正項 $n^2\pi^2 EI/(T_0 L^2)$ が小さければ純弦理論．
- **固有振動数（クランプ-クランプ，$EI$ 支配）**：固有値方程式
  $\cos(\beta_n L)\cosh(\beta_n L) = 1$ を解いて
  $\beta_n L = 4.7300, 7.8532, 10.9956,\ldots$，
  $$\omega_n = (\beta_n L)^2\sqrt{\frac{EI}{\mu L^4}}$$
  $T_0$ と $EI$ の両方が効く場合は閉形式がなく数値解．実用上は**曲げ境界層長**
  $$\ell_b \equiv \sqrt{\frac{EI}{T_0}}$$
  を使い，$\ell_b \ll L$ なら「純弦理論＋端部 $\ell_b$ 局所補正」で十分．
- **端部曲げ応力**：ピンでは境界条件として恒等的に $M(0)=M(L)=0$．
  クランプ／半剛性では端部に最大曲率が立つ．**疲労損傷はほぼ100%
  アンカレッジ近傍**で起こるので，疲労評価ではピン仮定は不可．
- **構造減衰**：クランプ端は端部に追加歪エネルギー散逸を生み，実効減衰がやや増える．

**実装方法（3種類）**：

1. **方法A：2点固定によるクランプ近似（EI不要）** ── 端から2番目の節点も固定する．
   Phase 1で簡易導入可能．境界層長が $L_0$ に固定されてしまうのが弱点．
2. **方法B：ゴーストノードによる接線拘束** ── 外側に仮想節点を置き，そこからの
   ばねで接線方向を保持．実装中程度．
3. **方法C：EI＋3点角度ばね＋端部回転ばね $k_\theta$** ── 最も物理的．
   $k_\theta=\infty$ でクランプ，$k_\theta=0$ でピン，中間で半剛性．感度解析向き．

**疲労評価には方法C必須．本案件では Phase 2 で方法C を導入する．**

#### (f) 動的境界（主桁・塔頂運動の注入）

**スコープに含む**．既存の `setBoundaryCondition` ラムダ機構で**追加実装ゼロ**で
実現可能：

```cpp
auto bc = [&](networkPoint* p) {
   if (p == cable->firstPoint) {
      p->X = X0_anchor + deck_displacement(t);  // 主桁運動を注入
      p->velocity = deck_velocity(t);
      p->acceleration.fill(0);
   }
   if (p == cable->lastPoint) {
      p->X = X0_pylon + pylon_displacement(t);  // 塔頂運動を注入
      p->velocity = pylon_velocity(t);
      p->acceleration.fill(0);
   }
};
```

これで以下が解析可能になる：

- **パラメトリック励振**：主桁鉛直振動による弦長変動 → 2:1共振
- **強制振動応答**：塔頂水平振動による上端強制変位
- **deck-cable 連成の片方向結合**（主桁→ケーブル）

なお，両方向連成（ケーブル張力反作用→主桁）は本コードのスコープ外．
必要なら BEM 浮体計算と同様に外部から張力を read-back する構造にする．

### 段階実装プラン

#### Phase 1（最小実装）

1. `getAeroForce()` を `getDragForce()` を雛形に作成（係数・密度を引数化）
2. 風速を `std::function<Tddd(Tddd, double)>` で受け取る
3. `getForce()` に `-alpha * mass * v` を追加（構造減衰）
4. `MooringLine`（または派生クラス）にプリテンション仕込みを追加
5. **境界条件はピン両端**（既存ラムダで `firstPoint`/`lastPoint` 固定）
6. `setEquilibriumState()` で初期サグ＋プリテンション形状を作る
7. 一様風で時刻歴 → 中央節点変位スペクトル → 弦理論
   $f_n = (n/2L)\sqrt{T_0/\mu}$ と照合（**Phase 1検証ゲート**）

これで**バフェッティング，ギャロッピング，空力減衰，固有モード**まで再現できる．
**ただし疲労評価はまだ不可（端部応力ゼロ）**．

#### Phase 2（疲労評価対応＋動的境界）

- **EI 導入**：3点角度ばねによる曲げ剛性．`networkLine` に `EI` メンバ追加，
  `getBendingForce()` を `getForce()` に統合
- **境界条件の3択切替**：`enum BCType {Pinned, Clamped, SemiRigid}`，
  半剛性は端部回転ばね $k_\theta$ で表現
- **動的境界**：`bc(p)` ラムダで `firstPoint`/`lastPoint` の位置・速度を時間関数化．
  主桁運動入力，塔頂運動入力，パラメトリック励振の各パターンを使用例として整備
- **端部応力出力**：端から数節点の曲率と曲げ応力を時刻歴保存
- Rayleigh 減衰係数を ζ から逆算するヘルパ
- 風速プロファイル＋乱流入力
- $C_D(\alpha), C_L(\alpha)$ を関数として（迎角依存）
- モード分解（FFT）出力

**Phase 2 検証ゲート**：

- クランプ端のオイラー梁固有値
  $f_n = (\beta_n L)^2/(2\pi L^2)\cdot\sqrt{EI/\mu}$，
  $\beta_n L = 4.730, 7.853,\ldots$ を再現
- 端部曲げ応力の時刻歴が物理的に妥当（プラスマイナス対称，中央でゼロ）
- 主共振条件 $\Omega = 2\omega_1$ でパラメトリック励振が発散

#### Phase 3（特殊現象）

- ウェイクオシレータ（Facchinetti の van der Pol 結合）：VIV ロックイン
- レインバイブレーション（Yamaguchi モデル）：水滴ライン位置を時間発展
- 半剛性端部の $k_\theta$ 同定：実橋計測の固有振動数から逆算
- 双方向連成（ケーブル→主桁の張力反作用）：必要なら別案件

### 実装上の注意点

#### CFL

橋梁ケーブルではプリテンション $T_0$ が支配的．taut string の横波位相速度は
分散関係 $\omega^2 = (T_0/\mu)k^2$ から非分散性で

$$c_\text{trans} = \sqrt{T_0/\mu}$$

明示時間積分の安定条件は $\Delta t \lesssim L_0/c_\text{trans}$．
例：$T_0$=4 MN, $\mu$=80 kg/m → $c_\text{trans}$=224 m/s．
$L_0$=1 m なら $\Delta t \lesssim 4$ ms．現状の明示 RK4 サブステップで通る範囲．

軸方向波（縦波）はもっと速い：$c_\text{long}=\sqrt{EA/\mu}$．例の値で
$c_\text{long}\approx 4200$ m/s．**横振動だけ見たい**なら軸モードを陰的に
処理するか，軸減衰を強めにかけて消す手もある．

Phase 2 で $EI$ を入れると**曲げ波は分散性**になり，$\omega = \sqrt{EI/\mu}\,k^2$．
最大離散波数は $k_\text{max}\approx \pi/L_0$ なので

$$\omega_\text{max}^\text{bend} \approx \frac{\pi^2}{L_0^2}\sqrt{\frac{EI}{\mu}},
\qquad
\Delta t \lesssim \frac{2}{\omega_\text{max}^\text{bend}}
= \frac{2 L_0^2}{\pi^2}\sqrt{\frac{\mu}{EI}}$$

**$L_0$ の二乗で効く**ので，節点を細かくするとサブステップ数が二次的に増える．
$EI$ が大きいときは陰解法か分割積分を検討．

#### 初期条件の作り方

1. プリテンションから自然長を計算
2. 両端固定（ピン）の境界条件を設定
3. 強い人工減衰で `setEquilibriumState()` 相当を回し静的釣り合いへ
4. 風荷重をオン，構造減衰を本来の値に戻す
5. 時刻歴ラン

Phase 2 でクランプを使う場合は，初期形状として両端の接線方向も指定する必要がある．

#### 検証ケース（必須）

**Phase 1**：

- **弦の固有振動数**：$f_n = (n/2L)\sqrt{T_0/\mu}$ ← 最初に確認
- **対数減衰率**：自由振動の包絡から $\delta = \ln(A_k/A_{k+1})$ を求め，
  $\zeta_s = \delta/\sqrt{4\pi^2 + \delta^2}$ が入力値と一致するか
- **空力減衰比**：n 次モードの空力減衰比は
  $$\zeta_{\text{aero},n} = \frac{\rho_\text{air} U D \,C_D}{2\,\mu\,\omega_n}$$
  風速 $U$ をかけて自由振動の対数減衰率増分が上式と一致するか
- **無次元 Scruton 数**：$Sc \equiv 2\mu\zeta_s/(\rho_\text{air} D^2)$．VIV 振幅予測の
  支配パラメータで，計測との比較に使う
- **ギャロッピング**：D 型断面係数（$\partial C_L/\partial\alpha + C_D < 0$）で
  $U > U_\text{cr}\sim 4\zeta_s\,m\omega_1/(\rho_\text{air}D|\partial C_L/\partial\alpha + C_D|)$
  の臨界風速を超えたら発散

**Phase 2**：

- **クランプ梁の固有振動数**：$\omega_n = (\beta_n L)^2\sqrt{EI/(\mu L^4)}$，
  $\beta_n L = 4.730, 7.853, 10.996,\ldots$ と照合
- **$EI$ による振動数補正（ピン-ピン）**：
  $f_n = (n/2L)\sqrt{T_0/\mu}\sqrt{1 + n^2\pi^2 EI/(T_0 L^2)}$
- **端部応力分布**：曲げ境界層長 $\ell_b = \sqrt{EI/T_0}$ 内に集中するか
- **VIV ロックイン参考量**：Strouhal 周波数 $f_s = St\,U/D$（円柱で $St\approx 0.20$），
  換算流速 $U_r = U/(f_n D)$，ロックイン中心 $U_r\approx 5$
- **パラメトリック励振**：主軸方向に振幅 $\Delta L$，振動数 $\Omega$ の支点加振を
  与えたとき，**主共振条件 $\Omega = 2\omega_n$** で発散．
  Mathieu 不安定領域 $\Omega/2\omega_n \in [1-\epsilon,1+\epsilon]$ が再現できるか

#### 出力候補

- 節点変位の時刻歴
- モード分解変位（FFT or 基底投影）
- 動的張力増分 ΔT(t)
- **端部曲げ応力時刻歴**（疲労評価用，Phase 2）
- **疲労損傷度**（Rainflow + S-N，Phase 3）
- 応答スペクトル

### 結論：最適エントリーモデル

> **質点ばね（既存コード）＋プリテンション仕込み＋準定常空力＋Rayleigh 減衰
> ＋ピン両端（Phase 1）→ EI＋クランプ／半剛性＋動的境界（Phase 2）**

理由：

1. 既存実装の構造をほぼ全て再利用できる（`MooringLine` のサブステップ，
   `networkLine`/`networkPoint` トポロジ，`RK_*_sub` 機構，`bc` ラムダ）
2. 横振動方程式を別途書かなくていい（幾何学的非線形ばねが taut string を内包）
3. 線形〜非線形遷移がシームレス
4. 拡張パスが綺麗（EI，回転ばね，ウェイクオシレータが独立に乗る）
5. 動的境界が `bc` ラムダ機構で**追加実装ゼロ**で入る

**避けるべき選択**：

- 弦の偏微分方程式をモード展開で別途解く → コード分裂，非線形が入らない
- FEM ビーム要素に置換 → 既存資産が無駄，CFL も別物
- ロッド要素フル実装 → 主要現象に対しオーバースペック

**Phase 1 検証ゲート**：弦理論の固有振動数を再現できること．  
**Phase 2 検証ゲート**：クランプ梁の固有振動数とパラメトリック共振を再現できること．  
これらが通れば，疲労評価まで含めた橋梁ケーブル風応答解析の基盤として使える．

この節は，将来 cable/係留/橋梁ケーブルの議論をするときの**基準メモ**である．
今後この話題を扱う際は，まずこの節を読み返し，以下の分類軸で整理して答えること．

### 将来の会話でまず確認すること

用語が混ざりやすいので，まず次のどの軸の話かを分ける．

| 軸 | 問い | 代表例 |
|---|---|---|
| 節点DOF | 何を未知数として更新するか | 節点並進，節点並進+回転 |
| 要素の運動学 | どの自由度を持つ要素か | spring, truss, beam, catenary cable |
| 構成則 / 制約 | どのように内力を出すか | 線形弾性，tension-only，Ernst等価，catenary平衡 |
| 幾何学の扱い | 変形後形状を力学へ戻すか | 幾何学線形，幾何学非線形 |
| 慣性の扱い | 質量をどう離散化するか | lumped mass, consistent mass, 質量なし |
| 解析手順 | どう解くか | 静解析，固有値，implicit動解析，explicit動解析 |
| 用途 | 何を見たいか | 橋梁全体系，ケーブル局部振動，洋上係留動力学 |

### 何度も混同しやすかった点

以下は過去の会話で何度も混ざった論点である．今後の返答では必ず分けて説明すること．

1. `truss / cable / beam` は**内力モデルや要素種別**であり，`lumped / consistent` や
   `explicit / implicit` と同列ではない．
2. `3D` であることと `幾何学非線形` は別である．  
   3Dでも初期形状まわりで線形化すれば幾何学線形である．
3. `細かいトラスに分割した` ことと `幾何学非線形を入れた` ことは別である．  
   現在形状で要素長・方向・内力を更新して初めて幾何学非線形になる．
4. `consistent mass` は「内部点を別に動かす」ことでも「回転を勝手に表す」ことでもない．  
   **更新するのは結局節点DOF**であり，違うのは慣性項の離散化である．
5. `cable` は1種類ではない．  
   `simple cable = tension-only truss 系` と  
   `full cable = catenary cable element 系` を分ける．

### 本メモで採用する短い定義

#### 幾何学非線形

> **変形後の形状（長さ・方向・つり合い位置）が，その後の内力や見かけ剛性に効くこと．**

頭の中では `変形後形状依存` と置き換えてよい．  
逆に幾何学線形は `初期形状まわりの線形化` である．

#### consistent mass

> **連続体の慣性項を，有限要素の補間関数と整合する形で離散化した質量行列．**

言い換えると，`連続体の慣性項を有限要素近似した結果として出てくるもの` である．

#### lumped mass

> **その慣性項の離散化を，節点集中に簡略化したもの．**

### 基礎方程式の流れ

軸力材の運動方程式は

$$
\rho A \ddot u = \frac{\partial N}{\partial s} + p
$$

である．有限要素近似

$$
u \approx N q_e
$$

を入れると，要素方程式

$$
M_e \ddot q_e + f_{\mathrm{int},e} = f_{\mathrm{ext},e}
$$

が出る．

このとき慣性項から自然に出るのが

$$
M_e^{\mathrm{cons}} = \int \rho A N^T N \, ds
$$

であり，これが `consistent mass` である．  
一方，これを節点集中に簡略化したものが `lumped mass` である．

**分岐するのは慣性項だけ**であり，内力モデルそのものは別軸である．

### 2節点トラス / simple cable の整理

#### 1D bar/truss の consistent mass

$$
M_e^{\mathrm{cons}} = \frac{\rho A L}{6}
\begin{bmatrix}
2 & 1 \\
1 & 2
\end{bmatrix}
$$

#### 2節点3Dトラスの consistent mass

$$
M_e^{\mathrm{cons}} = \frac{\rho A L}{6}
\begin{bmatrix}
2I_3 & I_3 \\
I_3 & 2I_3
\end{bmatrix}
$$

#### 2節点3Dトラスの lumped mass

$$
M_e^{\mathrm{lump}} = \frac{\rho A L}{2}
\begin{bmatrix}
I_3 & 0 \\
0 & I_3
\end{bmatrix}
$$

### 「truss」と「cable」の区別

今後は次のように分ける．

| 用語 | 本メモでの意味 |
|---|---|
| truss | 軸力のみ，通常は引張・圧縮とも負担 |
| tension-only truss | truss の圧縮切り |
| simple cable | 実質 `tension-only truss` またはその分割鎖 |
| Ernst等価要素 | サグ効果を等価剛性へ押し込んだ truss 系 |
| full cable / catenary cable | 自重・サグ・無応力長・初期張力を要素内で解く専用要素 |

### `full cable` と `simple cable` の違い

違いは「2次曲線を使うか」ではない．  
本質は次である．

- `simple cable`: 節点間距離から軸力を出す
- `full cable`: 要素内で catenary 平衡を解いて端力を返す

つまり違いは，**サグを要素外で分割近似するか，要素内で平衡として持つか**である．

### 現在の実装の正式な位置づけ

今の実装は次のように分類する．

| 軸 | 現在の実装 |
|---|---|
| 節点DOF | 節点並進 |
| 要素の運動学 | truss chain |
| 構成則 / 制約 | tension-only |
| 幾何学の扱い | 幾何学非線形（現在形状依存） |
| 慣性の扱い | lumped mass |
| 解析手順 | explicit RK4 |

短く書くなら

> **geometrically nonlinear lumped-mass explicit tension-only truss-chain model**

である．

### 「幾何学非線形でない」場合のイメージ

今の実装は毎回，現在の節点位置から

- 要素長
- 要素方向
- 張力方向

を更新している．これが幾何学非線形である．

反対に幾何学線形とは，

- 初期形状の方向で線形化
- 初期状態まわりの微小変位で扱う
- 一定の線形剛性で近似する

計算である．

**細かいトラスに分割しただけでは幾何学非線形にはならない**．

### 業界標準のざっくり整理

#### 橋梁

- 全体系解析では `beam/frame + equivalent truss` が多い
- ケーブル詳細では Ernst等価や catenary 要素
- 動的解析でも全体系では線形化が多い

#### 洋上係留

- 実務コードでは `lumped-mass line dynamics` が非常に一般的
- 簡易法として quasi-static catenary
- 詳細は fully dynamic line solver

つまり，**今の実装は橋梁全体系標準より，洋上係留の lumped-mass line model に近い**．
